Latent flow matching for uncertainty-aware 3D scene graph completion

A mobile robot observes only a fragment of an environment, yet must plan as though the remainder were known. This work completes the unobserved structure of a 3D scene graph generatively and reports a calibrated confidence for each inferred node and edge.

Venue — ICCAS 2026 Topic — Scene representation Code — [add link]

The problem

A scene graph constructed online from a robot's own observations is necessarily partial: rooms are partially viewed, objects occluded, and many relations never observed. Downstream planners nonetheless consume the graph as though complete, so each omission becomes a silent error, and a deterministic completion model renders that error indistinguishable from a confident prediction.

The approach

The observed graph is encoded into a latent space, and a flow-matching model is trained to transport noise to plausible complete graphs conditioned on that latent representation. Repeated sampling yields a distribution rather than a point estimate; agreement across samples provides a calibrated per-node and per-edge confidence measure.

Implications

A planner is able to distinguish structure that can be relied upon from structure requiring verification, and to direct the platform toward low-confidence regions — the same uncertainty signal employed in the exploration work described in the following study.

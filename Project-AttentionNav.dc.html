Attention-guided semantic navigation from pose, text and vision

Three heterogeneous inputs — the robot's pose, the textual specification of the goal, and the current visual observation — are fused through an attention mechanism and trained with a reward that increases exponentially as the goal is approached.

Venue — IJCAS 2025 Topic — Semantic navigation Code — [add link]

The problem

A policy that simply concatenates pose, language and visual features tends to rely on whichever modality is most readily predictive, while a sparse success reward provides little learning signal until the goal is reached by chance.

The approach

Cross-attention allows the goal text to select the visual regions relevant at the current pose, and an exponential reward function sharpens the learning signal as the distance to the goal decreases — sufficiently dense to guide the policy while discouraging unproductive wandering.
